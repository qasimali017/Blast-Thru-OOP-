Blast Thru Game

DESCRIPTION:

Break Thru is a challenging and strategic game developed using Unreal Engine Blueprints. It brings together nostalgic gameplay elements in a modern gaming environment. Players can enjoy a game filled with nostalgia with a modern touch.

MOTIVATION:

Qasim and Ali like games.

Qasim and Ali can code.

Games are just code.

Therefore, we can code our own game.

Modern times require modern approaches, hence the choice of Unreal Engine.

FEATURES:

Simple Gameplay: Engage in the simple goal of destroying all or as many bricks as possible.

Unique settings of levels and difficulty: Each level has different layout and an incresing difficulty

Relaxed Controls: Simple and easy to navigate interface.

Lives system: A max of 3 lives are given

Score board: Cummlative score obtained by destroying bricks

SOFTWARE USED -> UNREAL UNGINE

Modern & Versatile: A free, user-friendly game creation tool.

Blueprint System:

Simplifies traditional coding with a visual approach.

Blueprints are essentially classes that use OOP principles such as inheritance, encapsulation, and polymorphism.

Supports defining custom classes like "Ball" or using predefined classes for elements like cameras and physics.

Variables can be defined for elements like Ball Speed and Brick Strength.

Demonstrates OOP strengths like modularity.

RESOURCES USED:

Unreal Engine Documentation: Comprehensive guides, tutorials, and feature references.

Video Tutorials: Platforms like YouTube offer abundant Unreal Engine development tutorials.

ChatGPT Assistance: Helpful for troubleshooting and guiding potential solutions during development.

HOW TO PLAY:

A total of 3 levels to beat

Use the left and right arrow keys to move the paddle

Either destroy all bricks or lose all 3 lives

A total score will increment after each brick is hit

Bricks have colours which indicate how many hits needed to destroy

Make sure the ball does not fall down
